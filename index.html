📋 Descripción del Proyecto

Esta aplicación permite realizar análisis espacial avanzado y visualización de datos geoestadísticos de manera interactiva. Incluye herramientas para el procesamiento de datos espaciales, análisis exploratorio y generación de mapas dinámicos.

🔧 Tecnologías Utilizadas

R Shiny Leaflet sf ggplot2 DT Análisis Espacial Visualización

⚡ Características Principales

  • Carga y procesamiento de datos espaciales
  • Visualización interactiva con mapas
  • Análisis geoestadístico avanzado
  • Exportación de resultados
  • Interfaz intuitiva y responsive
